[00:00:00] 本视频为Claude Code零基础系统教程的完整讲解。内容涵盖从安装Git、VSCode和Claude Code，到如何绕过模型限制，介绍界面和权限系统，最终掌握tools工具、hooks钩子、skills技能、subagent子智能体以及自动化执行等核心功能。课程采用理论与实操结合的方式，目标是让用户能用Claude Code完成日常工作和项目开发。视频主讲人木子强调：不制造焦虑，提供AI时代解决方案。

[00:01:14] Git的安装与作用介绍

  • Git是代码版本管理工具，类似AI编程过程中的“后悔药”，能帮助回退错误版本，查看代码差异。
  • Git不是给人直接操作的，而是供AI自动使用。
  • 安装方法：
    • Windows用户下载安装包，官网地址可通过搜索“git install”获得。
    • macOS用户通过终端命令安装（需要先安装Homebrew）。
  • 安装完成后，即可进行版本控制。

[00:02:24] VSCode安装与功能介绍

  • VSCode提供图形化界面，显示文件树和代码，同时内置终端用以与Claude Code对话，操作更便捷。
  • 没有VSCode时，只能用纯命令行，体验较差。
  • 安装方式：到VSCode官网下载安装包，Windows双击安装，macOS拖拽安装。
  • 初次打开可跳过登录，安装完成后即可使用。

[00:03:36] Claude Code安装及模型切换

  • 在Claude Code官网复制命令行，粘贴至终端可一键安装。
  • Claude Code支持Anthropic Claude模型，也支持其他厂商模型，解决部分用户因限制无法使用Claude模型的问题。
  • 介绍两个开源项目：CC switch和claudecode Router，用于模型切换。
  • 以CC switch为例演示安装和添加其他模型（如minimax），通过输入API key启用新模型，Claude Code即切换至该模型。

[00:06:06] Claude Code终端界面详解

  • 通过VSCode打开终端，输入claudecode启动Claude Code。
  • 界面包含：
    • 右上角显示版本号、当前使用模型及推理强度。
    • 状态栏显示当前对话消耗的TOKEN数量、上下文使用比例及订阅额度（时间和天数）。
    • Claude Code自动展示思考过程和工作信息，包括调用的技能（skill）、写入文件等。
  • TOKEN消耗统计为累计值，帮助用户监控使用量。

[00:11:20] Claude Code图形化操作界面介绍

  • 通过VSCode左边栏安装“claudecode”插件后，右边栏弹出聊天界面。
  • 功能按钮：
    • 放大按钮：全屏显示。
    • 历史按钮：查看对话历史。
    • 加号按钮：新建对话线程。
  • 对话框支持上传文件、添加上下文（@文件名）以便与Claude Code交互文件内容。
  • 文件被添加到上下文后，Claude Code能读取、修改文件，实现代码协同编辑。
  • 斜杠按钮可调出所有命令，等同于终端内命令。
  • 权限系统包含四种模式：
    1. Plan Mode（计划模式）：仅制定计划，不修改文件。
    2. Ask Before Edit（默认模式）：修改前需用户同意。
    3. Edit Automatically（自动编辑）：自动同意编辑命令，但部分命令仍需确认。
    4. Bypass Permissions（权限全开）：完全自动执行，无需确认，风险最大。

[00:15:18] 权限模式实操示例

  • 在Plan Mode下让Claude Code制定个人博客开发计划，但不执行。
  • 切换至Ask Before Edit模式，执行过程中每次文件操作需用户确认。
  • 可临时授权本次会话自动编辑，切换至Edit Automatically模式。
  • 某些特殊命令（如open）在自动模式下仍需确认，可通过设置或终端命令启用Bypass Permissions模式实现完全自动化。

[00:20:07] Tools工具概念及调用流程

  • 大模型本身只能推理、生成文本，不能直接操作环境（如修改文件、创建文件夹）。
  • Tools是具体执行代码的“手”，负责实际修改项目文件或执行命令。
  • Claude Code会解析大模型的输出，调用相应工具完成任务。
  • 内置工具示例：写入文件（write）、网络搜索、网络抓取、终端命令执行（bash）等。
  • 通过示例演示将网页主题颜色从红色改为绿色的过程，工具调用清晰可见。

[00:22:44] Hooks钩子功能介绍

  • Hooks是程序运行关键节点的“挂钩”，允许插入自定义逻辑，对智能体执行过程进行监督和控制。
  • 常见钩子节点包括：任务结束前（stop）、子智能体结束前（sub agent stop）、工具调用前后（pre to use/post to use）、调用工具失败后等。
  • 作用示例：
    • 任务结束前检查代码是否完成测试，未完成则继续工作。
    • 子智能体结束时汇报操作文件列表，确认任务完成。
    • 调用工具后自动格式化代码、运行测试。
  • 创建钩子可通过自然语言指令完成，系统自动生成对应配置文件。

[00:26:17] Hooks实操示例

  • 创建一个stop钩子，确保代码改动有测试且无未完成待办，否则不允许结束任务。
  • 钩子生效后，每次任务结束前自动执行验收逻辑，保障代码质量。

[00:27:28] Skills技能介绍与示例

  • Skills是为特定任务（如制作PPT）封装的能力包，包含提示词、流程步骤及辅助资源（代码、参考资料）。
  • 结构上是一个文件夹，核心是taskskill.md文件，定义任务触发条件、执行流程及输出格式。
  • 官方示例：PPTX技能，支持PPT生成与编辑，内部包含多个Markdown文件及脚本，规范操作流程及设计规范。
  • 用户可自定义skills，打包特定任务流程。
  • 通过自然语言创建skill示例：自动调研并生成PPT的流程。

[00:32:22] Plugin插件概念

  • Plugin是skills、hooks和MCP Server（连接外部工具和数据源的API集合）的组合。
  • 作用是赋予Claude Code扩展能力，如视频生成、邮件处理、数据读取等。
  • 插件中的skills定义任务流程，hooks监管关键节点，MCP Server提供外部数据接口。
  • 管理插件命令/plugin可查看已安装及可安装插件列表。
  • 示例插件：front end design，默认安装，主要包含简单skill。

[00:34:38] Subagent子智能体介绍与创建

  • Agent是能独立执行任务、为用户决策和行动的智能体，区别于单纯聊天机器人。
  • Subagent是主智能体派出的辅助智能体，拥有独立上下文和权限，负责特定子任务，结果汇报主智能体。
  • 多个子智能体可并行执行，互不干扰。
  • 创建子智能体两种方法：直接对话创建，或终端命令_agents逐步创建。
  • 创建时需选择作用范围（项目级或个人级）、使用工具权限、模型及记忆存储策略。
  • 实例：创建一个负责信息搜索及交叉验证的子智能体，并展示其文件结构和记忆管理。

[00:40:45] 自动化任务调度

  • 使用_schedule命令创建定时任务，如每天8点自动调用子智能体搜索并验证前一天的AI新闻。
  • 自动化任务在云端运行，非本地执行。
  • 云端任务执行依赖于模型订阅，非Claude模型用户自动化功能受限。
  • 任务界面显示激活状态及运行历史，方便监控。

[00:42:02] 综合应用示例：网页AI APP开发

  • 选择并安装Superpowers插件，内置开发最佳实践，支持需求讨论、计划制定、分批执行及代码审查。
  • 通过自然语言描述创建“AI hook club”文案生成网页APP，支持用户输入主题，选择平台和内容类型，自动生成10个不同风格的爆款开头文案。
  • Superpowers先进行产品和技术头脑风暴，细化需求，确认语言、模型、输出方式、风格多样性等。
  • 设计阶段可以调整技术方案和页面布局。
  • 确认需求后，调用writing plans技能生成详细开发计划。
  • 两种开发执行模式：
    1. 子智能体驱动，任务分发给子智能体并行执行，主智能体审查。
    2. 主智能体单独对话执行，支持实时交互。
  • 选择子智能体驱动模式，Claude Code自动完成开发任务。
  • 本地运行时需配置Deepseek API key以启用AI功能。

[00:48:45] APP功能验收

  • 在浏览器地址访问本地运行的APP。
  • 测试生成10个不同视频开头，支持复制、收藏和查看历史，功能完整且稳定。

[00:50:02] Claude文件夹结构与说明

  • claudecode根目录下的claude文件夹管理所有扩展能力：
    • agents：子智能体定义及配置。
    • agent memory：子智能体持久记忆。
    • skills：各种技能包，包括官方及自定义技能。
    • plugins：项目级插件（若有）。
  • claude.md文件为项目说明书，定义项目技术栈、运行方式、限制及风格偏好等。
  • claude.md每次Claude Code工作时会作为软性上下文导入，优化任务执行效率和准确性。

[00:51:18] claude.md文件内容及作用

  • 自动生成命令_init可扫描项目代码自动生成该文件。
  • 包含项目架构、API配置、运行指令及注意事项。
  • 与hooks不同，claude.md提供软性规则，简洁且可自定义。
