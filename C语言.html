用户标识符（变量名、函数名等）必须满足：

  1. 只能由字母、数字、下划线组成；
  2. 不能以数字开头；
  3. 不能是 C 语言的关键字（如 int、float、do、goto 等）。
  4. 💡 小提示：
  • C 语言区分大小写，int 是关键字，但 INT 不是；
  • 下划线 _ 可以作为标识符的开头或中间字符，但减号 - 不可以。

二、常见错误写法 & 原因

错误写法错误原因
10110BC 语言不支持直接写二进制整数，也不允许用B做后缀

012.3整数常量不能包含小数点（带小数点的是浮点数）

三、拓展补充

  1. 长整型后缀：如果要表示长整型，可以在整数后加l或L，比如123L、0x1aL。
  2. 无符号整型后缀：如果要表示无符号整型，可以在整数后加u或U，比如123U、077U。
  3. 大小写说明：十六进制的x/X和字母a~f不区分大小写，0x1A和0X1a是等价的。

💡 小提示：在 C 语言中，没有专门的二进制整数常量写法，如果需要表示二进制，通常用十进制、八进制或十六进制间接表示，或者用字符串 / 宏定义处理。

C 语言中，科学计数法形式的实型常量必须满足以下格式：

尾数部分 E 指数部分

  • E（或e）前面必须有数字（可以是整数或小数）

  • E后面必须是整数（正 / 负号 + 整数，不能是小数） - 补充说明：

  • 除了科学计数法，实型常量也可以写成普通小数形式，如3.14、.5、10.（小数点前后可以缺省其中一边，但不能都缺省）。

  • E和e不区分大小写，2E0和2e0是等价的。
